## 媒体弹幕管理

「媒体与演员 → 媒体弹幕管理」页面代理 MisakaDanmaku 外部控制 API，**直接展示弹幕库原始数据**（不做本项目媒体匹配/汉化），支持：

- **弹幕库**：标题搜索过滤、详情抽屉查看「作品 → 数据源 → 分集」三级、删除分集/数据源/作品
- **搜索导入**：搜索 → 选择数据源 → 过滤分集/上移下移重排/一键重编序号 → `import/edited` 导入弹幕库，实时轮询进度

弹幕服务地址与 API 密钥在「基础配置 → 弹幕服务」配置（存 `backend/data/config.yaml`）。完整 API 文档见 `docs/danmu-api.md`。
